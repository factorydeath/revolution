# Developer utilities

Скрипты в этой папке не входят в рантайм бота и не импортируются из
`main.py`/`attack.py`. Они нужны только для разработки и обслуживания
`services.json`:

- `add_service.py` — добавить/обновить шаблон сервиса;
- `scan_bodies.py` — собрать тела ответов для анализа;
- `inspect_bodies.py` — просмотреть сохранённые тела;
- `verify_services.py` — проверить зарегистрированные эндпоинты;
- `prune_services.py` — удалить мёртвые сервисы по отчёту проверки.

Запускать из корня проекта через `.venv/bin/python tools/<script>.py`.
